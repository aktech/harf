The icon set is MIT licensed (LICENSE, from that commit). The logos are
trademarks of their owners and are used only to name each model's maker.

Each mark was compared with its owner's current one (the owner's GitHub
organisation picture or website icon, November 2026). Qwen's is the blue
mark the Qwen organisation now uses; StepFun's is its block mark; Grok
models use the Grok mark. xAI's company mark has changed and this package
has no copy of the new one, so the xAI provider has no logo. A model whose
maker has no logo here gets none.
